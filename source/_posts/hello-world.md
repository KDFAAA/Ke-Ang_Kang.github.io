## 关于这个博客

欢迎来到 **康 | 钝材笃斋**！这是一个基于 [Hexo](https://hexo.io/) 静态博客框架和 NexT 主题构建的个人技术博客。

## 技术栈

| 层级  | 技术选型          |
| --- | ------------- |
| 框架  | Hexo 8.x      |
| 主题  | NexT Gemini   |
| 渲染  | Stylus + Swig |
| 部署  | Github Pages  |

## 博客风格特性

- 🎨 **黑灰深蓝配色** — 极简暗色设计风格
